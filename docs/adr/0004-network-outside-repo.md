# NNUE networks live outside this repo and builds stay offline

Network files are published as release assets of a separate repository, [prozn/mudskipper-networks](https://github.com/prozn/mudskipper-networks), and supplied at build time. `network.txt` names the default network; `make net` downloads it with `curl` to `networks/default.bin` in the git-ignored `networks/`, the default `EVALFILE` that `.cargo/config.toml` sets. Setting `EVALFILE` points the build at any other file. The file is embedded with `include_bytes!`, and a file of the wrong size fails the build. `build.rs` never touches the network. Downloading in `build.rs` (Reckless's approach) and committing nets or using git-lfs were rejected. The goals are builds that work offline and give the same result every time, and a repo that holds only engine code. A build with no network available fails with a clear message.
